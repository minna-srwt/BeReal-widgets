Build your core flow (one screen at a time)

Then check the first version against your flow map, screen by screen:

1. Onboarding/Intro"Try Daily Duo" or "Pair up with a friend."
2. Main Action"Time to BeReal with Maya!"
3. Loading / Waiting"Finding your Duo…"
4. Success"You both posted! 🔆"
5. Error / Opt-out"Couldn't connect. Try again later."

Each screen should have:

A short header
One key visual (a gray photo box, a phone frame, or an icon)
Microcopy (1–2 lines max)
One button or action

Style it like BeReal:

Light background
Minimal text
Rounded buttons, no clutter

Fix one thing per message.

"Make the button on screen 2 say 'Invite Maya'" works much better than ten changes at once.

🧠Starting point, not the end-point. If everyone outsources their thinking to AI, everyone ends up thinking about the same thing. Use it to test your own thinking.
4️⃣

Add interactivity (clickable navigation)

Click every button yourself. Each one should take you exactly where your flow map says. Example navigation:

"Try It" → Pairing Screen
"Post" → Success Screen
"Try Again" → Error → Pairing Screen

If a button goes nowhere or to the wrong place, tell the AI exactly which one: "On the Pairing screen, the 'Confirm' button should go to screen 3."

In your doc: Click-Through Check
✅You're on track if you can click from the first screen to "done" and back to the start without getting stuck.
